About ABC GUI

The ABC GUI provides an intuitive graphical interface for the ABC tool, making it easier to work with logic synthesis and formal verification tasks.

Key Features:

  • Load files in multiple formats (AIGER, BLIF, Bench, PLA, Verilog)
  • Execute ABC commands with real-time output
  • Quick action buttons for common operations
  • Command history and status tracking

How to Use

  1. Launch the GUI: Run ./launch_gui.sh or python3 abc_gui.py
  2. Load a file: Click "Load File" and select an AIGER, BLIF, or other supported file
  3. Execute commands: Type commands in the command field or use quick action buttons
  4. View results: All output appears in the scrollable output window

Requirements: Python 3 with tkinter (included in most Python installations)
